2. Leçon complète : HTML

HTML = HyperText Markup Language. Il structure une page web.

À quoi sert HTML ?

HTML indique au navigateur quels éléments afficher : titres, paragraphes, liens, images, listes, tableaux, formulaires et sections.

La structure de base

<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <title>Ma première page</title>
</head>
<body>
  <h1>Bonjour Tidiane !</h1>
  <p>Je découvre HTML.</p>
</body>
</html>

Enregistre ce code dans un fichier nommé index.html, puis ouvre-le avec Chrome.

HTML➜ Titres : h1 à h6 Paragraphes : p Liens : a Images : img Listes : ul / ol Formulaires : form

Les balises essentielles

<h1> : titre principal. <p> : paragraphe. <a> : lien. <img> : image. <ul> et <li> : liste. <button> : bouton.

<h1>Mon école</h1>
<p>Bienvenue sur mon site.</p>
<a href="https://example.com">Visiter</a>
<img src="photo.jpg" alt="Une photo">

Balises ouvrantes et fermantes

La plupart des éléments commencent par une balise ouvrante et se terminent par une balise fermante.

<p>Voici un paragraphe.</p>
<h2>Un sous-titre</h2>

Quelques éléments, comme <img> et <br>, n’ont pas de balise fermante habituelle.

Les attributs

Un attribut donne une information supplémentaire à une balise.

<a href="contact.html">Contact</a>
<img src="photo.jpg" alt="Portrait">
<p class="important">À retenir</p>

href indique une destination, src indique une ressource, alt décrit une image et class permet de sélectionner des éléments en CSS.

Conseil : écris d’abord une petite page, ouvre-la dans le navigateur, puis modifie un élément à la fois. Observe le résultat pour comprendre le code.

3. Leçon : CSS

CSS contrôle l’apparence, les couleurs, les espaces et la disposition des éléments.
CSS➜CouleursTypographieEspacementsBorduresMise en pageResponsive

CSS dans une page

<style>
body {
  font-family: Arial, sans-serif;
  background: #eff6ff;
}
h1 { color: #2563eb; }
p { font-size: 18px; }
</style>

Le sélecteur choisit les éléments, et les propriétés définissent leur apparence.

CSS séparé

Crée un fichier style.css puis relie-le au HTML dans la partie head.

<link rel="stylesheet"
      href="style.css">

Cette méthode facilite l’organisation et la maintenance du projet.

Quelques propriétés

  • color : couleur du texte
  • background : arrière-plan
  • font-size : taille du texte
  • margin : marge extérieure
  • padding : espace intérieur
  • border-radius : coins arrondis

4. Découvrir JavaScript

JavaScript permet de réagir aux clics, vérifier des formulaires et modifier une page.
JavaScript➜VariablesConditionsBouclesFonctionsÉvénements

Une variable

const prenom = "Tidiane";
let score = 0;
score = score + 1;
console.log(prenom, score);

const déclare une liaison qui ne sera pas réaffectée, et let une variable réaffectable.

Une condition

const note = 15;
if (note >= 10) {
  console.log("Admis");
} else {
  console.log("À améliorer");
}

Une fonction

function saluer(nom) {
  return "Bonjour " + nom;
}
console.log(saluer("Tidiane"));

Une fonction rassemble des instructions que l’on peut réutiliser.

5. Découvrir Python

Python est souvent utilisé pour apprendre la programmation, automatiser des tâches, analyser des données et créer des services.
Python➜VariablesConditionsBouclesFonctionsModules

Premier programme

prenom = "Tidiane"
print("Bonjour", prenom)

print() affiche une valeur à l’écran.

Une condition

note = 14
if note >= 10:
    print("Admis")
else:
    print("À améliorer")

En Python, l’indentation organise les blocs d’instructions.

Une boucle

for nombre in range(1, 6):
    print(nombre)

Cette boucle affiche les nombres de 1 à 5.

6. Découvrir Kotlin

Kotlin est un langage moderne utilisé notamment pour le développement Android.
Kotlin➜val / varTypesConditionsFonctionsAndroid

Premier exemple

fun main() {
    val prenom = "Tidiane"
    println("Bonjour $prenom")
}

val définit une valeur non réaffectable ; var une variable réaffectable.

Une fonction

fun addition(a: Int, b: Int): Int {
    return a + b
}

fun main() {
    println(addition(3, 4))
}

Pour commencer Android

Installe Android Studio, crée un projet, découvre Kotlin et Jetpack Compose, puis exécute l’application dans un émulateur ou sur un téléphone.

7. Découvrir Flutter

Flutter permet de construire des interfaces multiplateformes avec le langage Dart.
Flutter➜DartWidgetsÉcransNavigationTests

Un exemple minimal

import 'package:flutter/material.dart';

void main() {
  runApp(const MonApp());
}

class MonApp extends StatelessWidget {
  const MonApp({super.key});

  @override
  Widget build(BuildContext context) {
    return const MaterialApp(
      home: Scaffold(
        body: Center(
          child: Text('Bonjour Tidiane !'),
        ),
      ),
    );
  }
}

Étapes d’un projet Flutter

  1. Installer Flutter et un éditeur.
  2. Créer un projet.
  3. Construire les écrans avec des widgets.
  4. Ajouter la navigation et les données.
  5. Tester sur émulateur et téléphone.
  6. Préparer la publication.

9. Créer un prototype avec Google AI Studio

Les intitulés de l’interface peuvent évoluer : suis les options disponibles dans ton compte.
  1. Ouvre Google AI Studio et connecte-toi à ton compte Google.
  2. Choisis l’espace de prototypage ou l’option de création d’application disponible dans ton interface.
  3. Décris clairement ton application : son public, ses écrans, ses fonctions et son apparence.
  4. Demande une première version limitée à quelques fonctions principales.
  5. Examine le résultat et teste chaque bouton, chaque formulaire et chaque écran.
  6. Demande des corrections précises, une par une, puis teste à nouveau.
  7. Avant la publication, vérifie la sécurité, les données, les droits d’accès et le fonctionnement sur téléphone.

Exemple de demande

Crée un prototype mobile-first
pour gérer les devoirs d'une classe.
Écrans : accueil, liste des devoirs,
détails d'un devoir et paramètres.
Style : coloré, lisible et accessible.
Ajoute des données de démonstration.
Explique comment tester chaque fonction.

Attention au prototype

Un prototype visuel n’est pas automatiquement une application prête pour les vrais utilisateurs. Vérifie la sauvegarde des données, les comptes, les autorisations, les erreurs et la sécurité avant de publier.

11. Les étapes du vrai développement

Même avec l’IA, un projet solide suit une méthode claire.
Application➜1. Besoin➜2. Cahier des charges➜3. Maquette➜4. Architecture➜5. Code➜6. Tests et publication
  1. Définir le problème : qui utilisera l’application et quel problème doit-elle résoudre ?
  2. Écrire le cahier des charges : liste les utilisateurs, les fonctions, les données et les contraintes.
  3. Faire la maquette : dessine les écrans sur papier ou avec un outil de conception.
  4. Choisir les technologies : par exemple HTML, CSS et JavaScript pour un site web ; Kotlin pour Android natif ; Flutter avec Dart pour une application multiplateforme.
  5. Préparer les fichiers : organise les dossiers, le code, les images et les ressources.
  6. Coder progressivement : réalise une fonction à la fois, sans attendre que tout soit terminé pour lancer le projet.
  7. Tester : vérifie les scénarios normaux, les erreurs, les petits écrans et les connexions faibles si nécessaire.
  8. Corriger et documenter : explique comment installer et utiliser le projet.
  9. Publier : choisis un hébergement ou un magasin d’applications selon la plateforme, puis surveille les retours.
  10. Maintenir : corrige les problèmes, améliore l’application et protège les données.
