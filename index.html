2. Leçon complète : HTML

HTML = HyperText Markup Language. Il structure une page web.

À quoi sert HTML ?

Il indique au navigateur quels éléments afficher : titres, paragraphes, liens, images, listes, formulaires, tableaux et vidéos. HTML n’est pas un langage de programmation à logique générale : c’est un langage de balisage.

La structure de base à connaître

<!DOCTYPE html>
<html lang="fr">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>Ma première page</title>
  </head>
  <body>
    <h1>Bonjour le monde !</h1>
    <p>Je découvre HTML.</p>
  </body>
</html>

Enregistre le fichier sous index.html, puis ouvre-le dans un navigateur.

Les balises essentielles

<h1> titre principal<h2> sous-titre<p> paragraphe<a> lien<img> image<ul> liste<li> élément<button> bouton<form> formulaire<div> bloc générique<input> saisie<table> tableau
Balise double : <p>Texte</p> possède une ouverture et une fermeture. Balise vide : <img src="photo.jpg" alt="Description"> n’a pas de balise de fermeture.

Attributs et liens

Un attribut ajoute une information à la balise. href définit la destination d’un lien, src le fichier image, alt une description de l’image, class une classe de style et id un identifiant unique.

<a href="https://example.com">
  Visiter le site
</a>

<img src="livre.jpg"
     alt="Un livre ouvert">

Mini-tutoriel : créer une page

  1. Ouvre un éditeur : VS Code, WebCode ou un éditeur HTML sur téléphone.
  2. Crée un fichier nommé index.html.
  3. Écris la structure HTML de base ci-dessus.
  4. Ajoute un titre, un paragraphe et une liste.
  5. Enregistre et ouvre le fichier dans Chrome.
  6. Modifie le texte, actualise la page et observe le résultat.

3. CSS : rendre le site beau

CSS = Cascading Style Sheets. Il contrôle les couleurs, tailles, espacements, dispositions et animations.

Exemple CSS

body {
  font-family: Arial, sans-serif;
  background: #eff6ff;
  color: #172554;
}
h1 {
  color: #2563eb;
  text-align: center;
}
.card {
  padding: 20px;
  border-radius: 16px;
  box-shadow: 0 8px 20px #0001;
}

La règle CSS contient un sélecteur (h1), puis des propriétés et leurs valeurs.

Comment relier CSS et HTML ?

<head>
  <link rel="stylesheet"
        href="style.css">
</head>

Place ce lien dans head. Le fichier style.css doit se trouver au bon emplacement.

Astuce : teste une propriété à la fois. Si rien ne change, vérifie le nom du fichier et le chemin.

4. JavaScript : rendre la page interactive

Il réagit aux clics, valide les formulaires, calcule des valeurs et met à jour la page.

Premier exemple

const nom = "Tidiane";
function saluer() {
  alert("Bonjour " + nom + " !");
}
// On déclenche la fonction au clic

À retenir

  • const : variable qu’on ne réaffecte pas.
  • let : variable qu’on peut réaffecter.
  • if / else : choisir selon une condition.
  • function : regrouper des instructions.
  • addEventListener : réagir à un événement.

5. Python : apprendre la logique

Python sert à l’automatisation, aux données, aux scripts, à l’IA et aux serveurs web.

Exemple simple

nom = input("Ton nom : ")
print("Bonjour", nom)

note = 15
if note >= 10:
    print("Admis")
else:
    print("À renforcer")

Python utilise l’indentation (les espaces en début de ligne) pour délimiter les blocs.

Ordre pour débuter

  1. Afficher avec print().
  2. Variables et types de données.
  3. Lire avec input().
  4. Conditions if/else.
  5. Boucles for/while.
  6. Fonctions, listes, dictionnaires, fichiers.
  7. Petits projets puis bibliothèques.

6. Kotlin : coder pour Android

Kotlin est un langage moderne utilisé pour développer des applications Android.

Exemple Kotlin

fun main() {
    val nom = "Tidiane"
    println("Bonjour $nom !")
    val note = 15
    if (note >= 10) {
        println("Admis")
    } else {
        println("À renforcer")
    }
}

Parcours Android

  1. Découvrir variables, conditions et fonctions.
  2. Installer Android Studio si l’ordinateur le permet.
  3. Créer un projet Android simple.
  4. Construire l’interface avec Jetpack Compose ou XML.
  5. Tester sur émulateur ou téléphone.
  6. Corriger les erreurs et préparer la publication.

7. Flutter : une application sur plusieurs plateformes

Flutter est un framework de Google qui utilise le langage Dart pour créer des interfaces mobiles, web et desktop.

Exemple Dart / Flutter

import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(
  home: Scaffold(
    body: Center(
      child: Text('Bonjour Tidiane !'),
    ),
  ),
));

Les grandes étapes

  1. Apprendre les bases de Dart.
  2. Installer Flutter SDK et un éditeur compatible.
  3. Créer un projet et lancer l’application.
  4. Composer l’écran avec des widgets.
  5. Ajouter navigation, données et formulaires.
  6. Tester sur plusieurs tailles d’écran.
Flutter n’est pas un langage : c’est un framework. Le langage associé est Dart.

8. Bien utiliser ChatGPT, Gemini et les autres IA

Une IA est un assistant : donne-lui un objectif clair, vérifie ses réponses et garde le contrôle du projet.

💬 ChatGPT

Pour expliquer une notion, préparer un plan, proposer du code, repérer une erreur, écrire des tests et améliorer une interface.

Prompt exemple : « Explique-moi cette erreur en français simple. Donne la cause probable, la correction et une méthode pour vérifier. Ne réécris pas tout le projet. »

✨ Gemini

Pour explorer des idées, comparer des solutions, travailler avec des contenus pris en charge et demander une seconde analyse.

Prompt exemple : « Analyse ce cahier des charges. Liste les fonctionnalités, les écrans, les données et les risques. Pose-moi des questions si une information manque. »

🧪 Google AI Studio

Pour expérimenter les modèles Gemini, tester des instructions, ajuster les paramètres disponibles et créer des prototypes à partir d’une consigne.

Les fonctions et les limites changent : vérifie les options visibles dans ton compte et ne publie jamais de clé secrète dans le code du navigateur.

9. Créer un prototype avec Google AI Studio

Un flux de travail pédagogique : les boutons exacts peuvent évoluer selon l’interface du service.
  1. Ouvre Google AI Studio et connecte-toi avec ton compte Google.
  2. Choisis l’espace de prototypage ou de création d’application disponible dans ton interface.
  3. Décris l’application précisément : qui l’utilise, quels écrans, quelles fonctions, quelles couleurs, quelles langues.
  4. Demande une première version simple : un écran d’accueil et une fonction principale.
  5. Teste l’aperçu. Clique sur chaque bouton et vérifie les erreurs, les petits écrans et les champs de saisie.
  6. Demande des modifications ciblées : « Corrige uniquement le formulaire, conserve les autres écrans. »
  7. Vérifie le code, les dépendances, les données et la sécurité. Les prototypes générés ne sont pas automatiquement prêts pour un vrai déploiement.
  8. Exporte ou copie les fichiers si cette option est proposée, puis teste le projet dans l’environnement approprié.
Important : ne mets pas de mot de passe, de clé API, de données personnelles d’élèves ou d’informations privées dans un prompt public. Une clé API doit être protégée côté serveur.

11. Le vrai codage : suivre un ordre professionnel

Le vibe coding accélère la création, mais il ne supprime pas l’analyse, les tests et la maintenance.
  1. Définir le problème : qui a besoin de l’application et quelle difficulté résout-elle ?
  2. Écrire le cahier des charges : objectifs, utilisateurs, fonctionnalités, limites et critères de réussite.
  3. Faire des croquis : dessiner les écrans et la navigation avant le code.
  4. Choisir la technologie : site web (HTML/CSS/JS), serveur (par exemple Python), Android (Kotlin) ou multiplateforme (Flutter/Dart).
  5. Organiser les fichiers : séparer interface, logique, données, images et documentation.
  6. Construire une petite version : réaliser d’abord une fonction essentielle, pas tout en une fois.
  7. Tester chaque fonction : cas normal, champs vides, erreurs, réseau faible, écran mobile.
  8. Contrôler la sécurité : permissions, mots de passe, accès, sauvegardes, données personnelles.
  9. Utiliser Git : sauvegarder l’historique des modifications et pouvoir revenir en arrière.
  10. Faire tester par une personne : observer les difficultés réelles et améliorer l’ergonomie.
  11. Déployer : publier sur un hébergement ou une plateforme appropriée.
  12. Maintenir : corriger les bugs, sauvegarder les données et mettre à jour les dépendances.

Exemple de structure d’un petit site

mon-projet/
├── index.html      # contenu
├── style.css       # présentation
├── script.js       # interactions
├── images/         # illustrations
└── README.md       # explication du projet

Une bonne boucle de travail

ConstruirePlanifierCoderExécuterTesterDéboguerDocumenter

Répète la boucle pour chaque fonctionnalité. Demande à l’IA d’expliquer ses changements et vérifie-les toi-même.
